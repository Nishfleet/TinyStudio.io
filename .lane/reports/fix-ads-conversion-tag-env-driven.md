# Lane report: tinystudio-io lane 1 — dead Google Ads conversion placeholder

Item: `[unreviewed-by-opus] The funnel's only Google Ads conversion measurement is dead by construction: placeholder tag`

## What was dead

- `public/brief-requested.html` hardcoded the gtag loader with placeholder
  `AW-XXXXXXXXX`.
- `public/brief-requested.js` fired the conversion event to the same
  placeholder (`AW-XXXXXXXXX/YYYYYYYYYYYYYYYYYYY`).
- The production CSP in `src/worker.js` blocked `googletagmanager.com`
  entirely, so even a real ID pasted in could never load or record.

## The fix

- The conversion tag is now generated by the worker at request time from
  `GOOGLE_ADS_CONVERSION_ID` / `GOOGLE_ADS_CONVERSION_LABEL` and emitted only
  on `/brief-requested` when both are configured and well-formed
  (`AW-` + 6-15 digits; 10-50 alphanumeric label).
- With either value missing or malformed, the page ships with no tag at all —
  a dead tag is never served.
- gtag's CSP allowances are scoped to that one noindex page's response
  (`GOOGLE_ADS_CSP`); every other page keeps the strict CSP.
- CI (`scripts/check-site.mjs`) now refuses any placeholder or hardcoded gtag
  in `public/` or `src/worker.js`, so the dead-by-construction shape cannot
  return.
- `specs/003-wellness-clinic-launch/tracking-setup.md` documents the
  `wrangler secret put` commands that activate the tag once the console-side
  conversion action exists.

## Files changed

- `src/worker.js` — env-driven tag generation, page-scoped CSP, request-time
  injection into `/brief-requested` (HTML) and `/brief-requested.js`.
- `public/brief-requested.html` — placeholder gtag loader removed; comment now
  explains the worker injection.
- `public/brief-requested.js` — placeholder conversion event removed; static
  file is a documented no-op, generated content comes from the worker.
- `scripts/check-site.mjs` — static source guards that forbid the placeholder
  / hardcoded gtag shape.
- `scripts/test-agent-worker.mjs` — 3 new tests (unconfigured, configured,
  partial/malformed).
- `specs/003-wellness-clinic-launch/tracking-setup.md` — secret-put activation
  steps replace the "paste into brief-requested.html" instructions.

## Validation

`npm test` green on `origin/main` + this change:

- check-site (6), heading-hierarchy (7), sitemap (16), worker (76 — includes
  the 3 new Google Ads tests), agent-UI (8), product-contract (8), first-viewport (4).
- New worker tests cover: no tag + strict CSP while unconfigured; injected
  loader + generated script + page-scoped CSP when configured; nothing emitted
  for partial or malformed config (including an injection-shaped value).
