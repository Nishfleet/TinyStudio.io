## Summary

The failure mode the item describes — `/brief-requested` shipping a hardcoded
gtag loader with the placeholder conversion id `AW-XXXXXXXXX`, the static
`brief-requested.js` firing a conversion event to the same placeholder, and
the production CSP blocking `googletagmanager.com` entirely — **no longer
exists, on source or on the live site**. The fix is already merged in
`origin/main` as PR #172 (`60d045c`, "fix(worker): make the Google Ads
conversion tag env-driven instead of a dead placeholder", merged 2026-08-14).

With both `GOOGLE_ADS_CONVERSION_ID` and `GOOGLE_ADS_CONVERSION_LABEL`
unconfigured (as they are in production today), the worker emits **no tag at
all** — a dead tag is never served. Measured live on 2026-08-14: zero
`googletagmanager.com` references in the served `/brief-requested` HTML, a
static no-op `brief-requested.js`, and the strict CSP on both responses.

## What was dead (pre-fix state, from git history)

- `public/brief-requested.html` hardcoded the gtag loader with placeholder
  `AW-XXXXXXXXX` (from the page's first commit `c90c8a4` / PR #14).
- `public/brief-requested.js` fired `gtag('event', 'conversion', …)` to
  `AW-XXXXXXXXX/YYYYYYYYYYYYYYYYYYY`.
- The production CSP (`script-src 'self' https://static.cloudflareinsights.com`)
  blocked `googletagmanager.com` entirely, so even a real id pasted in could
  never load or record.

## The merged fix (PR #172, 60d045c)

- The conversion tag is now generated by the worker at request time from
  `GOOGLE_ADS_CONVERSION_ID` / `GOOGLE_ADS_CONVERSION_LABEL`, emitted only on
  `/brief-requested` when both are configured and well-formed (`AW-` +
  6-15 digits; 10-50 alphanumeric label — strict patterns, safe to
  interpolate).
- With either value missing or malformed, the page ships with no tag at all.
- gtag's CSP allowances (`GOOGLE_ADS_CSP`) are scoped to that one noindex
  page's response; every other page keeps the strict CSP.
- `public/brief-requested.js` is now a documented static no-op; the worker
  serves the generated conversion script in its place when configured.
- CI (`scripts/check-site.mjs`) refuses any placeholder or hardcoded gtag in
  `public/` or `src/worker.js`, and requires the env-driven wiring to stay
  wired — the dead-by-construction shape cannot return.
- `specs/003-wellness-clinic-launch/tracking-setup.md` documents the
  `wrangler secret put` steps that activate the tag once the console-side
  conversion action exists.
