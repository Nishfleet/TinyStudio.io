## What was dead (pre-#172)

- `public/brief-requested.html` hardcoded the gtag loader with placeholder
  `AW-XXXXXXXXX` (from the page's first commit `c90c8a4` / PR #14).
- `public/brief-requested.js` fired the conversion event to the same
  placeholder (`AW-XXXXXXXXX/YYYYYYYYYYYYYYYYYYY`).
- The production CSP (`script-src 'self'
  https://static.cloudflareinsights.com`) blocked `googletagmanager.com`
  entirely, so even a real id pasted in could never load or record.

## The merged fix (PR #172, `60d045c`)

- The conversion tag is generated by the worker at request time from
  `GOOGLE_ADS_CONVERSION_ID` / `GOOGLE_ADS_CONVERSION_LABEL`, emitted only
  on `/brief-requested` when both are configured and well-formed
  (`GOOGLE_ADS_ID_PATTERN` `/^AW-\d{6,15}$/`, `GOOGLE_ADS_LABEL_PATTERN`
  `/^[A-Za-z0-9_-]{10,50}$/` — strict patterns, safe to interpolate).
- With either value missing or malformed, the page ships with **no tag at
  all** — a dead tag is never served.
- gtag's CSP allowances (`GOOGLE_ADS_CSP`) are scoped to that one noindex
  page's response; every other page keeps the strict CSP.
- `public/brief-requested.js` is a documented static no-op; the worker
  serves the generated conversion script in its place when configured.
- CI (`scripts/check-site.mjs` "Google Ads conversion tag" guard) refuses
  any placeholder or hardcoded gtag in `public/` or `src/worker.js`, and
  requires the env-driven wiring to stay wired — the dead-by-construction
  shape cannot return.
- `specs/003-wellness-clinic-launch/tracking-setup.md` documents the
  `wrangler secret put` steps that activate the tag once the console-side
  conversion action exists.
